## 2. Installing Foundry

Foundry is the fastest Solidity development framework. It includes:

- `forge` — compile, test, deploy
- `cast` — interact with chains (read state, send transactions)
- `anvil` — local Ethereum node (fork mainnet or run fresh)
- `chisel` — Solidity REPL (try code snippets interactively)

### Installation

```bash
# Install foundryup (Foundry's installer)
curl -L https://foundry.paradigm.xyz | bash

# Restart your shell, then install Foundry
foundryup
```

Verify:
```bash
forge --version
cast --version
anvil --version
```

### Alternative: Hardhat

[Hardhat](https://hardhat.org) is a popular JavaScript/TypeScript-based framework. We mention it for awareness but use Foundry throughout this course.

```bash
# If you ever need Hardhat
npx hardhat init
```

## 3. Your First Foundry Project

```bash
# Create a new project
forge init hello_foundry
cd hello_foundry

# Directory structure
# ├── lib/          (dependencies, e.g. forge-std)
# ├── script/       (deployment scripts)
# ├── src/          (smart contracts)
# ├── test/         (tests)
# └── foundry.toml  (configuration)
```

### Compile

```bash
forge build
# Compiles contracts in src/ → artifacts in out/
```

### Run Tests

```bash
forge test
# Runs all tests in test/
# Output:
# [PASS] test_Increment() (gas: 28334)
# [PASS] test_SetNumber() (gas: 26319)
```

### Run the Default Contract

```solidity
// src/Counter.sol (generated by forge init)
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract Counter {
    uint256 public number;

    function setNumber(uint256 newNumber) public {
        number = newNumber;
    }

    function increment() public {
        number++;
    }
}
```

## 4. Running a Local Node with `anvil`

```bash
# Start anvil (local Ethereum node)
anvil

# Output:
# Available Accounts
# ==================
# (0) 0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266 (10000 ETH)
# (1) 0x70997970C51812dc3A010C7d01b50e0d17dc79C8 (10000 ETH)
# ...
#
# Private Keys
# ==================
# (0) 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80
# ...
#
# Chain ID: 31337
# Listening on 127.0.0.1:8545
```

### Deploy to Local Node

```bash
# In a new terminal
forge script script/Counter.s.sol:CounterScript \
  --rpc-url http://localhost:8545 \
  --private-key 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80 \
  --broadcast
```

### Interact with Deployed Contract

```bash
# Call a read function (no gas)
cast call 0x5FbDB2315678afecb367f032d93F642f64180aa3 "number()(uint256)"

# Send a transaction
cast send 0x5FbDB2315678afecb367f032d93F642f64180aa3 "increment()" \
  --private-key 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80

# Check updated value
cast call 0x5FbDB2315678afecb367f032d93F642f64180aa3 "number()(uint256)"
# Output: 1
```

## 5. Forking Mainnet

Test against real mainnet state without spending real ETH:

```bash
# Fork mainnet at latest block
anvil --fork-url https://eth-mainnet.g.alchemy.com/v2/YOUR_KEY

# Or fork at a specific block
anvil --fork-url https://eth-mainnet.g.alchemy.com/v2/YOUR_KEY \
      --fork-block-number 19000000
```

Now you can interact with real contracts (Uniswap, Aave, etc.) using your local anvil accounts.

```bash
# Call USDC balanceOf on mainnet fork
cast call 0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48 \
  "balanceOf(address)(uint256)" 0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266
```

## 6. Connecting to Testnets

### Get an RPC URL

1. Go to [Alchemy](https://www.alchemy.com) or [Infura](https://infura.io)
2. Create a free account
3. Create a new app → select **Sepolia** network
4. Copy your HTTPS RPC URL

### Get Testnet ETH

- [Sepolia Faucet (Alchemy)](https://sepoliafaucet.com)
- [Sepolia Faucet (QuickNode)](https://faucet.quicknode.com/ethereum/sepolia)
- [Sepolia PoW Faucet](https://sepolia-faucet.pk910.de) (mine testnet ETH)

### Configure Foundry

```bash
# Set environment variable
export SEPOLIA_RPC_URL="https://eth-sepolia.g.alchemy.com/v2/YOUR_KEY"
export PRIVATE_KEY="0xYourPrivateKey"  # NEVER commit this!

# Add to foundry.toml
# [rpc_endpoints]
# sepolia = "${SEPOLIA_RPC_URL}"
```

## 8. Project Configuration — `foundry.toml`

```toml
# foundry.toml
[profile.default]
src = "src"
out = "out"
libs = ["lib"]
solc_version = "0.8.24"
optimizer = true
optimizer_runs = 200

[profile.default.fmt]
line_length = 100
tab_width = 4

# RPC endpoints (use env vars for secrets)
[rpc_endpoints]
sepolia = "${SEPOLIA_RPC_URL}"
mainnet = "${MAINNET_RPC_URL}"

# Etherscan API keys for verification
[etherscan]
sepolia = { key = "${ETHERSCAN_API_KEY}" }
mainnet = { key = "${ETHERSCAN_API_KEY}" }
```

## 9. Mini-Project: End-to-End Local Deployment

Create a full workflow:

```bash
# 1. Start local node
anvil &

# 2. Create project
forge init my_first_dapp && cd my_first_dapp

# 3. Build
forge build

# 4. Test
forge test -vv

# 5. Deploy
forge script script/Counter.s.sol:CounterScript \
  --rpc-url http://localhost:8545 \
  --private-key 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80 \
  --broadcast

# 6. Interact
CONTRACT=0x5FbDB2315678afecb367f032d93F642f64180aa3
cast call $CONTRACT "number()(uint256)"
cast send $CONTRACT "increment()" \
  --private-key 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80
cast call $CONTRACT "number()(uint256)"
```

## Common Pitfalls

| Pitfall | Solution |
|---------|----------|
| `forge: command not found` | Restart your shell or add `~/.foundry/bin` to PATH |
| `anvil` port 8545 already in use | `lsof -i :8545` to find the process, or use `anvil --port 8546` |
| Sepolia faucet gives 0 ETH | Try a different faucet; some require Alchemy account |
| Tests fail with "Compiler version mismatch" | Set `solc_version` in `foundry.toml` to match your pragma |
